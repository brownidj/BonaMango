# BonaManĝo icon

Master: `bona-mangxo.png` (1024 × 1024). Generated with the built-in image_gen tool.
The Flutter asset is mirrored under `flutter_app/assets/images/icons/`; native
Apple, Android, web and Windows icons are size-specific exports of this master.

Prompt: Photorealistic square app icon of a blue mango on an opaque green
background, with natural skin texture and a slight soft shadow. Mango oriented
from top left (stem) to bottom right (tip); a small stem has an attached leaf
occupying much of the top-right quadrant. Clear small-size silhouette, safe
margins for OS corner clipping, studio lighting, no lettering or watermark.

The current version is the approved brighter edit: first approximately 15%, then
an additional 10% brightness lift, made with the built-in image_gen tool. The
original master was backed up under ignored `data/backups/`. Native icons and
Flutter golden screenshots were updated to the approved image.

To regenerate platform sizes from the master on macOS:

```zsh
.venv/bin/python scripts/export_icons.py
```
